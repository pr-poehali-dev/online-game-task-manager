## 1. Колонка «На удержании»

### Что добавлено
Отдельная колонка слева от To Do — не привязана к статусам деплоя. Задачу
любого статуса можно временно отложить сюда перетаскиванием карточки, не
меняя её статус деплоя. По умолчанию колонка свёрнута в узкую полосу с
вертикальной надписью HOLD и счётчиком задач; клик разворачивает её в обычный
вид колонки. При снятии задачи с удержания пользователь сам выбирает, в какую
колонку её вернуть (To Do / In Progress / Done).

### Файлы для переноса
```
backend/tasks/index.py
src/pages/index/Board.tsx
src/pages/index/CreateTaskModal.tsx
src/pages/index/TaskModalHeader.tsx
src/pages/index/TaskModalMeta.tsx
src/pages/index/shared.tsx
```

### Проверка
- На доске слева от To Do должна быть узкая свёрнутая полоса с вертикальной
  надписью HOLD и счётчиком задач.
- Перетащите карточку на эту полосу — задача должна переместиться «На
  удержании» без изменения статуса деплоя.
- Разверните колонку (клик по полосе или стрелке) — должны появиться карточки
  задач и кнопка «Добавить».
- Снимите задачу с удержания перетаскиванием в другую колонку — статус деплоя
  должен запросить выбор (если у колонки несколько вариантов).

## 2. Уведомления в Telegram по задачам «На удержании»

### Что изменилось
Пока задача находится в колонке «На удержании», назначение исполнителей и
изменение статуса деплоя больше не отправляют сообщение в Telegram — команду
не дёргают по временно отложенным задачам. Внутреннее уведомление (колокольчик
в приложении) при этом создаётся как обычно. Комментарии к задаче на
удержании продолжают уведомлять в Telegram без изменений. Как только задачу
переносят из «На удержании» в любую другую колонку, уведомления в Telegram
возобновляются в полном объёме.

### Файлы для переноса
```
backend/tasks/index.py
```
(входит также в список файлов раздела 1 — копируется один раз)

### Проверка
- Назначьте исполнителя на задачу в колонке «На удержании» — в приложении
  (колокольчик) уведомление должно появиться, в Telegram — нет.
- Переместите ту же задачу в другую колонку и снова смените исполнителя —
  уведомление должно прийти и в Telegram.

## 3. Фильтрация задач по серверу в разделе «Патчи»

### Что изменилось
В разделе «Патчи» выпадающий список «Без выбранной задачи» теперь показывает
только задачи того сервера, вкладка которого выбрана (С4х1, HFx3 old, HF new).
При переключении вкладки сервера, если ранее выбранная задача относится к
другому серверу, выбор в списке автоматически сбрасывается.

### Файлы для переноса
```
src/pages/index/IndexMain.tsx
src/pages/index/Patches.tsx
```

### Проверка
- Откройте «Патчи», выберите вкладку сервера — в выпадающем списке задач
  должны быть только задачи этого сервера.
- Выберите задачу, затем переключите вкладку сервера на другой — выбор в
  списке должен сброситься на «Без выбранной задачи».

Файл `backend/tasks/index.py` в этой папке уже адаптирован под своё

заданы под ваш сервер (см. шаг 3 инструкции `deploy/README.md`).

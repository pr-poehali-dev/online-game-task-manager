и `update/2026-09-15-3/`. Одна правка: на карточке задачи на доске теперь виден номер

## 0. Порядок действий (коротко)

1. Скопируйте `src/pages/index/BoardTaskCard.tsx` поверх своего.
2. Пересоберите фронтенд (`npm run build`).
3. `npm install` и `pip install` не требуются, backend не трогаем.

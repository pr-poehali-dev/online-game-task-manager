# Обновления от 15 сентября (пятый патч): поиск по номеру задачи + копирование ссылки

Небольшой апдейт поверх уже установленных `update/2026-09-15/` … `update/2026-09-15-4/`.
Две связанные правки на доске задач:

1. **Поиск по номеру задачи.** На панели фильтров доски (там же, где фильтры по серверу
   и спринту) появилось поле поиска. Если ввести номер задачи (например `141` или
   `#141`) — находится ровно эта задача. Если ввести любой другой текст — ищет по
   вхождению в название, как обычный поиск.
2. **Клик по номеру на карточке копирует ссылку.** Номер задачи на карточке (`#141`,
   добавлен в одном из предыдущих апдейтов) теперь кликабелен отдельно от всей
   карточки: клик копирует прямую ссылку на задачу (`.../task/141`) в буфер обмена и
   показывает всплывающее уведомление «Ссылка на задачу скопирована» — не открывая
   саму карточку. Открытие карточки по клику в любом другом месте работает как раньше.

Апдейт безопасный: **миграций нет**, новых зависимостей нет (`sonner` для уведомлений
уже используется в проекте).

---

## 0. Порядок действий (коротко)

1. Скопируйте 4 файла из `src/pages/` поверх своих.
2. Пересоберите фронтенд (`npm run build`).
3. `npm install` и `pip install` не требуются, backend не трогаем.

---

## Проверки, выполненные при сборке

- **Хардкоды платформы.** Правка не работает с S3/CDN — упоминаний адресов платформы
  нет. Ссылка на задачу собирается из `window.location.origin` — того самого домена,
  на котором открыт сайт, никаких хардкодов.
- **Миграции.** Нет — используются существующие поля задачи (`id`, `title`).
- **Зависимости.** Не менялись, `sonner` (уведомления) уже был в проекте.
- **Сборка.** `npm run build` и `tsc --noEmit` проходят без ошибок по изменённым файлам.

# Обновления от 18 сентября (3): веб-поиск в обычном чате с ИИ

Точечный фикс поверх всех уже установленных `update/2026-09-18-2/` и более ранних. Одна тема.

1. **Обычный чат с ИИ теперь может искать в интернете.** Раньше модель отвечала только по своим
   внутренним знаниям, без доступа к актуальной информации из сети — из-за этого на редких/узких
   вопросах (например список предметов конкретного игрового квеста) ответ мог быть неполным или
   неверным, хотя тот же самый вопрос та же модель на других сервисах с поиском отвечала верно.
   Теперь модель сама решает, когда ей нужно поискать в сети, и подключает поиск автоматически —
   от сотрудника никаких дополнительных действий не требуется.

## Как это работает

`backend/ai/generate.py`:
- `handle_send_message` и `handle_regenerate` — в запрос к AI Tunnel (`/chat/completions`)
  добавлен параметр `'tools': [{'type': 'aitunnel:web_search'}]`. Это встроенный серверный
  инструмент AI Tunnel — поиск выполняется на его стороне, а не в коде backend, и включается
  для ВСЕХ сообщений в обычном чате (сотруднику не нужно ничего переключать).
- Модель сама решает, обращаться ли к поиску для конкретного сообщения — на простые вопросы
  («переведи текст», «напиши код») она отвечает как раньше, без похода в сеть.
- Не все модели умеют пользоваться этим инструментом — если конкретная модель его не
  поддерживает, она просто проигнорирует параметр и ответит как обычно, ошибки не будет.
- Стоимость поиска уже включена в общую стоимость запроса (`cost_rub`), отдельной оплаты нет.
- Заполнение документов по шаблону, генерация изображений/видео, автоназвание диалога — не
  менялись, веб-поиск подключён только к обычному текстовому чату.

## 0. Порядок действий

1. Скопируйте файл поверх своего:
   - `backend/ai/generate.py`
2. Миграции БД — **не требуются**, схема не менялась.
3. npm/pip-зависимости — **не требуются**, список не менялся.
4. Пересобирать фронтенд — **не требуется**, это чисто backend-правка.
5. Перезапустите backend (self-hosted `deploy/server.py` грузит все функции при старте процесса):
   ```bash
   sudo systemctl restart era-backend.service
   ```
6. Nginx этот апдейт не затрагивает.

## Проверка после установки

- Откройте раздел «AI» → обычный чат, задайте вопрос про редкий/узкоспециальный факт (например
  список предметов конкретного игрового квеста) — ответ должен стать заметно точнее, чем раньше.
- Простые вопросы («напиши код на Python», «переведи фразу») должны отвечаться так же быстро, как
  раньше — модель не обязана искать в сети на каждое сообщение.

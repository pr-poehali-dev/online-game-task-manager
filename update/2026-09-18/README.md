# Обновления от 18 сентября: подсветка кода в редакторе + цвет блоков кода

Небольшой апдейт поверх всех уже установленных `update/2026-09-15*/`. Две связанные
темы вокруг оформления блоков кода в редакторе задач/статей/идей (`RichEditor.tsx`,
использующий Tiptap):

1. **Забытый фикс цвета кода (был сделан раньше, но не попал ни в один патч).**
   Инлайн-код (`` `код` ``) и блоки кода (```` ```код``` ````) в редакторе и в
   готовых статьях/задачах теперь оформлены так же, как на этой платформе:
   инлайн-код — янтарным акцентным цветом на приглушённом фоне, блок кода — на
   заметно более светлой подложке с тонкой рамкой (раньше подложка блока была
   почти того же цвета, что и страница, и визуально не читалась как отдельный
   элемент).
2. **Подсветка синтаксиса в блоках кода.** Раньше весь текст внутри блока кода
   выводился одним цветом — теперь ключевые слова, строки, числа, комментарии и
   названия функций подсвечиваются разными цветами (как в обычной IDE), в тон
   общей тёмной палитре проекта. Работает автоматически, без ручного выбора
   языка — подсветка определяет язык по содержимому кода. Раскраска одинаковая
   и в самом редакторе, и в уже сохранённых статьях/задачах/идеях (те же CSS-классы
   `hljs-*`, что расставляет редактор при сохранении HTML, читаются одинаково в
   обоих местах).

## Как это работает

### Забытый фикс цвета (тема 1)

Это чисто CSS-правка `src/index.css`, сделанная раньше по ходу разработки (коммит
`[FIX] Убрал лишние бейджи из редактора`), но по ошибке не скопированная ни в один
из патчей `update/2026-09-15*/` — они собирались по диапазону файлов конкретных
фич и не задели `src/index.css`. Правка:
- `.tiptap-editor .ProseMirror code` и `.kb-content code` (инлайн-код) — добавлен
  `color: hsl(var(--primary))` (янтарный акцент).
- `.tiptap-editor .ProseMirror pre` и `.kb-content pre` (блок кода) — фон поднят с
  `hsl(220 18% 6%)` до `hsl(220 14% 16%)` (заметно светлее) и добавлена тонкая рамка
  `border: 1px solid hsl(var(--border))`.
- `.tiptap-editor .ProseMirror pre code` и `.kb-content pre code` — добавлен
  `color: hsl(var(--foreground))`, чтобы текст внутри блока (без подсветки синтаксиса)
  оставался читаемым на новом более светлом фоне.

### Подсветка синтаксиса (тема 2)

Новая зависимость `@tiptap/extension-code-block-lowlight` (обёртка над `lowlight` —
лёгкий движок подсветки на базе `highlight.js`, без Node-специфичных зависимостей,
работает в браузере). Подключена в `src/components/RichEditor.tsx`:
- `StarterKit` теперь собирается с `codeBlock: false` — его встроенный узел `codeBlock`
  выключен, потому что конфликтует по имени с новым `CodeBlockLowlight`.
- `CodeBlockLowlight.configure({ lowlight })` добавлен в список расширений редактора;
  `lowlight` создаётся через `createLowlight(common)` — `common` это набор самых
  распространённых языков (JS/TS/Python/JSON/CSS/HTML/Bash/SQL и т.п.), полный словарь
  всех языков `lowlight` не подключён намеренно — это лишний вес в сборке фронтенда,
  который не нужен для внутреннего задачника.
- Кнопка «Блок кода» в панели инструментов и горячая клавиша ``` работают без изменений
  — API узла `codeBlock` совместим у обоих расширений, `editor.chain().focus()
  .toggleCodeBlock().run()` не менялся.
- В `src/index.css` добавлена палитра подсветки — правила по классам `.hljs-keyword`,
  `.hljs-string`, `.hljs-title`/`.hljs-built_in`, `.hljs-number`/`.hljs-type`,
  `.hljs-comment` и т.д., которые `lowlight` расставляет по токенам кода. Правила
  продублированы для `.tiptap-editor .ProseMirror pre` (сам редактор) и для
  `.kb-content pre` (уже сохранённая статья/задача/идея — рендерится через
  `dangerouslySetInnerHTML` тем же HTML, который сохранил редактор, поэтому классы
  должны совпасть, иначе подсветка пропадала бы после сохранения).

## 0. Порядок действий (коротко)

1. Скопируйте файлы поверх своих:
   - `package.json` — **только для того, чтобы свериться со своим файлом**: если у вас
     уже есть строки `"@tiptap/extension-code-block-lowlight"` и `"lowlight"` в разделе
     `dependencies` (проверьте `grep lowlight package.json`), просто добавьте в свой
     `package.json` две строки вручную — заменять весь файл не нужно, чтобы не затереть
     другие ваши правки, если они есть.
   - `src/components/RichEditor.tsx`
   - `src/index.css`
2. Установите новые npm-зависимости:
   ```bash
   npm install @tiptap/extension-code-block-lowlight lowlight
   ```
3. Пересоберите фронтенд:
   ```bash
   npm run build
   ```
4. Backend, миграции и Nginx этот апдейт не затрагивает — перезапускать backend/nginx
   не нужно.

## Проверка после установки

Откройте любую задачу (или статью базы знаний) в режиме редактирования, вставьте блок
кода (кнопка со значком `</>` в панели редактора или горячая клавиша ``` ) и введите,
например:

```js
function foo() {
  const x = 1; // comment
  return "hi";
}
```

Ключевые слова (`function`, `const`, `return`) должны окраситься в один цвет, строка
`"hi"` — в другой, комментарий — приглушённым курсивом. Инлайн-код (одно слово в
обратных кавычках) должен быть янтарного цвета. Сохраните задачу/статью и откройте её
в обычном (не редактируемом) виде — подсветка должна остаться такой же.
